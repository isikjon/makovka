Политика конфиденциальности мобильного приложения «Пекарня»

Редакция от 2 октября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности (далее — Политика) описывает, какие персональные данные собирает мобильное приложение «Пекарня» (далее — Приложение), с какой целью они обрабатываются, кому передаются и как пользователь может ими управлять.

Оператором персональных данных является ИП Каменев А.Н. (далее — Оператор), владелец программы лояльности пекарни. Обработка персональных данных осуществляется в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

Устанавливая Приложение и проходя регистрацию, пользователь подтверждает, что ознакомлен с настоящей Политикой и даёт согласие на обработку своих персональных данных на описанных в ней условиях.

2. Какие данные мы собираем

Данные, которые пользователь указывает сам:

  • Номер мобильного телефона — обязателен, используется для входа в Приложение по одноразовому SMS-коду и для идентификации карты лояльности;
  • Имя, фамилия, адрес электронной почты, дата рождения, пол — указываются по желанию в профиле пользователя.

Данные, которые формируются при использовании программы лояльности:

  • Номер карты лояльности, привязанной к номеру телефона пользователя;
  • История покупок по карте лояльности: дата покупки, сумма чека, размер предоставленной скидки и пекарня, в которой совершена покупка. Состав чека (перечень товаров) в Приложении не собирается и не отображается.

Технические данные:

  • Версия Приложения и операционной системы, сведения об ошибках работы Приложения — только для обеспечения его стабильной работы.

Приложение не собирает данные о местоположении устройства, не получает доступ к контактам, камере, микрофону, фотографиям и файлам пользователя, не использует рекламные идентификаторы и сторонние сервисы аналитики.

3. Цели обработки

  • Регистрация и авторизация пользователя в Приложении;
  • Выпуск и обслуживание карты лояльности, идентификация пользователя на кассе по QR-коду;
  • Предоставление скидок и иных преимуществ программы лояльности;
  • Отображение истории покупок и информации о скидках в Приложении;
  • Информирование об акциях и предложениях пекарни внутри Приложения;
  • Обработка обращений пользователей и поддержка.

4. Передача данных третьим лицам

Оператор передаёт персональные данные только в объёме, необходимом для работы программы лояльности:

  • Учётная система iiko (ООО «АЙКО») — используется пекарней для учёта продаж и ведения карт лояльности. В систему iiko передаются номер телефона и, при наличии, имя, фамилия и дата рождения пользователя; из неё Приложение получает номер карты лояльности и историю покупок по ней.
  • Сервис доставки SMS-сообщений — используется исключительно для отправки одноразового кода входа. Сервису передаётся только номер телефона пользователя.

Оператор не продаёт персональные данные и не передаёт их третьим лицам в рекламных целях. Персональные данные могут быть раскрыты по законному требованию уполномоченных государственных органов.

5. Хранение и защита данных

Персональные данные хранятся на серверах Оператора. Обмен данными между Приложением и сервером осуществляется по защищённому протоколу HTTPS. Доступ к данным имеют только уполномоченные сотрудники Оператора, которым он необходим для выполнения служебных обязанностей.

Персональные данные хранятся до момента удаления аккаунта пользователя, если иной срок не установлен законодательством.

  • изменить или уточнить данные профиля непосредственно в Приложении;
  • отозвать согласие на обработку персональных данных и потребовать удаления аккаунта;
  • обжаловать действия Оператора в уполномоченном органе по защите прав субъектов персональных данных.
